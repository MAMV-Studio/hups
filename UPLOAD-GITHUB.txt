Hups 59 ja Google-kirjautuminen

1. Käytä Hupsin nykyistä Supabase-projektia. Jos version 58 tilit.sql
   on jo ajettu, sama tietokantamuutos on valmiina.
   Pidä nykyiset Vercelin SUPABASE-muuttujat käytössä.
2. Avaa Supabasessa Authentication → Sign In / Providers → Google.
   Kopioi sieltä Callback URL.
3. Avaa Google Auth Platform (https://console.cloud.google.com/auth/).
   Määritä Branding ja Audience, ja luo Clients-kohdassa Web application -asiakas.
   Lisää Hupsin julkinen origin (https://oma-hups-osoite, ilman polkua)
   kohtaan Authorized JavaScript origins.
   Lisää Supabasesta kopioitu Callback URL kohtaan Authorized redirect URIs.
   Jos sovellus on tilassa Testing, lisää omat testiosoitteet Test users -listaan.
4. Syötä Googlen Client ID ja Client Secret Supabasen Google-asetuksiin,
   ota Google käyttöön ja tallenna. Client Secret kuuluu vain Supabaseen.
5. Supabase → Authentication → URL Configuration: aseta Site URL:ksi
   Hupsin julkinen osoite ja lisää Redirect URLs -listaan sama osoite
   muodossa https://oma-hups-osoite/?profiili=1.
6. Pura Hups-Vercel-59.zip ja päivitä GitHub. Kun Vercel näyttää Ready,
   testaa Kirjaudu Googlella, profiilin tallennus ja vieraspeli.

Supabasen ohje: https://supabase.com/docs/guides/auth/social-sign-in/auth-google
