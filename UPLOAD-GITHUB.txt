1. Pura Hups-Vercel-25.zip koneelle (Pura kaikki / Extract all).
2. Avaa purettu kansio, jossa näkyvät app, public ja package.json.
3. GitHubin tyhjässä hups-repositoriossa paina uploading an existing file.
4. Vedä puretun kansion SISÄLTÖ latausalueelle.
5. Tarkista että package.json on juuritasolla, ei ylimääräisen kansion alla.
6. Paina Commit changes ja lähetä kuva avautuvasta tiedostolistasta.

Seuraavaksi luodaan Hupsin oma Supabase-tietokanta ja tuodaan repositorio Verceliin.
Yksinpeli toimii ilman tietokantaa. Kaveripeli tarvitsee README.md:n asetukset.
